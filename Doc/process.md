## Ciclo de Trabalho
Scrum + Kanban
* Sprint de X semanas 

## DoR - Uma tarefa so entra na sprint se:
 - Descrição esta clara
 - Critérios de aceite definidos 
 - Dependências indentificadas 



## DoD - Uma tarefa esta concluida quando: 
 - Código esta implementado 
 - Testes estao passando 
 - PR aprovado 
 - Merge realizado


## PR/Reviews
* Sistema de bombeiro com rodízio
* Mínimo de um revisor 

* PR deve ter descrição clara das mudanças
* PR deve ser pequeno e conciso 
* Não aprovar o próprio PR
* Prazo maximo de review dentro de 24h
* Tentar resolver todos os comentarios antes do merge
